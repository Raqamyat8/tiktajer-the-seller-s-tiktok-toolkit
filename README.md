# TikTajer: The Seller's TikTok Toolkit

Create a professional Arabic website called "TikTajer" (تيك تاجر).

The website must target Arabic e-commerce sellers who use TikTok.

========================

MAIN STRUCTURE (VERY IMPORTANT)

========================

Create a MULTI-PAGE website (not a single page).

Each tool MUST have its own separate page with a unique URL.

Pages:

1. Homepage (/)

- Clear headline about helping sellers grow with TikTok tools

- Short explanation

- Buttons linking to tools

- Section linking to blog articles

2. Tools Section:

Create these 3 tools, each in a separate page:

- /tools/tiktok-script-generator

  (Tool: Extract and generate TikTok scripts from video ideas)

- /tools/tiktok-content-planner

  (Tool: Generate 30-day TikTok content plan for stores)

- /tools/image-optimizer

  (Tool: Remove background and compress product images)

Each tool page must include:

- SEO title (Arabic keyword focused)

- Meta description

- H1 title

- Explanation of the tool

- Input/output interface

- CTA button (Try Now)

- Internal links to related blog articles

IMPORTANT:

DO NOT put all tools in one page.

========================

BLOG SECTION

========================

Create a blog:

- /blog (main blog page)

Each article must have its own page:

example:

- /blog/tiktok-marketing-guide

- /blog/product-image-optimization

Create at least 5 Arabic SEO articles.

Each article must:

- Target one keyword

- Be at least 1200 words

- Use H1, H2, H3 headings

- Include internal links to tools

- Include a section: "جرب الأداة الآن"

========================

NAVIGATION MENU

========================

- Home

- Tools

- Blog

========================

LEGAL PAGES (IMPORTANT FOR GOOGLE)

========================

Create:

- /privacy-policy

- /terms-of-service

- /contact-us

Each page must be professional and trustworthy.

========================

SEO REQUIREMENTS

========================

- Fast loading

- Mobile friendly

- Clean URLs

- Arabic language optimized

- Each page must have meta title and description

========================

DESIGN

========================

- Modern, clean, simple

- Focus on conversions

- Arabic RTL layout

========================

GOAL

========================

The website must be optimized for Google SEO and ranking.
